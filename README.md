# 🌟 Project Overview 

This project demonstrates a complete **Machine Learning deployment pipeline** using **Python**, **Scikit-Learn**, and **Flask**.

The application allows users to enter medical measurements through a clean and responsive interface and instantly predicts whether breast cancer is detected. Along with the prediction, the app displays the **confidence score** and the **trained model accuracy**, making the results more informative and user-friendly.

This project is ideal for beginners who want to learn how to build, train, save, and deploy a machine learning model as a real-world web application.

# 📂 Dataset Information

The model is trained using the **Breast Cancer Wisconsin Diagnostic Dataset**, available in **Scikit-Learn**.

### Prediction Classes

| Prediction | Description |
|------------|-------------|
| 🟢 Benign | No Disease Detected |
| 🔴 Malignant | Disease Detected |

The dataset contains diagnostic measurements extracted from digitized images of breast cell nuclei and is widely used as a benchmark dataset for binary classification problems.
